## Projeto em destaque

### Bairro Alerta

Protótipo desenvolvido em um **hackathon de cerca de 1h30**: uma rede comunitária de alertas hiperlocais sobre desastres climáticos, como enchentes, temporais, deslizamentos e calor extremo.

**O que o MVP faz**

- Cadastro e login de usuários
- Criação de alertas com título, tipo, descrição, local, raio (km) e gravidade
- Mural de alertas

**Tecnologias**

| Camada | Stack |
|---|---|
| Frontend | HTML, CSS e JavaScript |
| Backend | Node.js, TypeScript e Express |
| Banco de dados | PostgreSQL com Prisma |
| Autenticação | JWT e Bcrypt |

**Próximas etapas planejadas**

- [ ] Mapa de alertas com Leaflet e OpenStreetMap
- [ ] Notificações
- [ ] Votação comunitária
- [ ] Integração com dados da Defesa Civil e do CEMADEN
